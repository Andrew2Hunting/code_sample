This folder contains all the necessary code to assemble the data for the IRA related subawards. The prepawardids.do should be run first which creates a list of all the IRA related award ID's needed to query the API (awardids.csv). Then requestdata.py can be run to make the API requests and pull data for each of those ID's, one at a time. As it stands, this is the slowest/weakest part of assembling the dataset. We let our code run on an AWS server for three days to gather all the data. If time is a concern, I would recommend editing the code to make parallel API requests. Once this is done, it will produce a dataset of the subawards in the folder above as all_subawards_results_API.csv.
